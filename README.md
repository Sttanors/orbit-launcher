# Orbit

Единый игровой лаунчер для Linux: локальная библиотека Steam и свои игры в полноэкранном интерфейсе с обложками. Не требует Steam Web API и ключей. Для запуска Steam-игр нужен вход в соответствующий аккаунт в клиенте Steam.

## Запуск

```bash
bash start.sh
```

На компьютере, где уже создан локальный ярлык `Orbit.desktop`, можно открывать его. Ярлык содержит абсолютный путь и не включён в репозиторий. Оконный режим: `bash start.sh --windowed`.

Требуется Python 3.10+ и PySide6 с QtWebEngine. Установка зависимостей:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python launcher.py
```

## Возможности

- Steam из обычной установки и Flatpak; несколько библиотек, локальные обложки, запуск через Steam с его настройками Proton.
- Установка определяется по манифесту Steam и наличию каталога. Зарегистрированные игры с отключённых дисков остаются в библиотеке с отметкой недоступности. «Открыть в Steam» передаёт управление клиенту; установка и обновления выполняются там.
- Свои игры: ELF, AppImage, исполняемые скрипты; выбор файла и обложки, аргументы запуска, рабочая папка. Клавиша E открывает редактирование добавленной игры; идентификатор, избранное и история сохраняются. Нужны права на выполнение. Windows EXE требуют заранее настроенного скрипта Wine/Proton, который можно добавить как игру.
- Поиск, фильтры, сортировка, избранное, история запусков из Orbit. Удаление своей игры из списка сохраняет её файлы.
- Обычный запуск использует `steam -silent -applaunch APPID`, чтобы не вызывать главное окно Steam через URI. Orbit остаётся фоном до появления игры. Steam может показывать обязательные окна входа, обновления, установки или выбора варианта запуска. Успешная передача команды не гарантирует, что сама игра запустилась; сообщения Steam и игры остаются в их ведении.
- По умолчанию полный экран; интерфейс на русском.

## Два аккаунта Steam

Orbit читает сохранённые аккаунты из `config/loginusers.vdf`. Выбери Steam-игру → **E / Параметры** → укажи аккаунт с нужной лицензией → Сохранить. Можно выбрать «Текущий аккаунт Steam», чтобы не привязывать игру.

Первоначальная привязка берётся из LastOwner установочного манифеста, если этот аккаунт сохранён. Это последний известный владелец установки, а не проверка лицензии. Для игр второго аккаунта при необходимости поправь выбор вручную.

При запуске из другого аккаунта Orbit предлагает переключение. После подтверждения он отправляет Steam штатную команду `-shutdown`, ждёт завершения до 45 секунд без принудительного убийства процессов, затем выполняет `steam -silent -login ACCOUNT`. Игра запускается отдельной командой только после подтверждения входа именно в выбранный аккаунт по текущему сеансу Steam. На вход отводится 3 минуты, затем Orbit сообщает об ошибке и не запускает игру. Пока обнаружена запущенная игра Steam, переключение блокируется. На время переключения Orbit временно занимает полный экран поверх окон Steam. После подтверждённого входа главное окно Steam сворачивается через xdotool (X11 / Xwayland), а режим поверх остальных окон снимается до запуска игры. Системные окна входа доступны по F8: эта команда сразу снимает защитный экран. xdotool необязателен для запуска Orbit, но нужен для сворачивания главного окна Steam на X11 / Xwayland. Orbit не меняет файлы авторизации и не читает/хранит пароли; Steam использует свои сохранённые данные и при необходимости показывает вход / Steam Guard. Клиент может потребовать повторную авторизацию — полностью скрыть этот этап нельзя. Выбор аккаунта не даёт права запускать чужую лицензию.

Активный аккаунт определяется по работающему Steam и событиям входа из журнала текущего сеанса. Если определить его не удалось, Orbit предлагает явное переключение. Во время ожидания можно открыть Steam: F8 / X на геймпаде, или отменить отложенный запуск: Esc / B. Отмена не возвращает прежний аккаунт и не отменяет уже отправленную команду завершения Steam. При закрытии Orbit до окончания переключения отложенный запуск отменяется.

## Пропуск подготовки шейдеров Steam

Меню (F10) → «Пропуск подготовки шейдеров Steam» → «Перезапустить Steam и применить настройку».

Orbit запускает клиент с `STEAM_ENABLE_SHADER_CACHE_MANAGEMENT=0`. Это отключает систему предварительного кэширования Steam для всего сеанса клиента, а не нажимает кнопку «Пропустить» в окне. Для Flatpak переменная передаётся через `flatpak run --env=…`. Настройка сохраняется в Orbit и учитывается при смене аккаунтов. Если Steam уже работал, нужна его полная перезагрузка: переменные нового процесса не меняют существующий клиент. Запущенная игра блокирует перезапуск.

Возможны подёргивания при компиляции шейдеров во время игры. Собственная компиляция игры не отключается. Вернуть обычное поведение можно тем же переключателем и перезапуском Steam. Если запустить Steam вне Orbit, настройка Orbit не применяется автоматически. Для применения сохранённого режима при запуске лаунчера: `bash start.sh --apply-steam-settings`.

Документация Valve: [Steam client update — shader cache management](https://store.steampowered.com/news/posts/?enddate=1526517539&feed=steam_client).

## Управление

Полная справка есть внутри приложения: **F1**, либо меню → «Клавиатура и геймпад». Буквенные сочетания работают по физической клавише независимо от русской / английской раскладки, кроме ввода в текстовые поля.

| Действие | Клавиатура | Геймпад Xbox / PlayStation |
| --- | --- | --- |
| Выбрать игру | Стрелки | Крестовина / левый стик |
| Запустить выбранную | Enter | A / × |
| Избранное | F | Y / △ |
| Параметры игры / аккаунт Steam | E или F2 | X / □ |
| Добавить игру | N или Insert | R3 |
| Удалить свою игру из списка | Delete, с подтверждением | Параметры → Убрать из списка |
| Вкладки | PageUp / PageDown | LB / RB (L1 / R1) |
| Фильтры | [ / ] | LT / RT (L2 / R2) |
| Первая / последняя игра | Home / End | — |
| Поиск | / или Ctrl+F | L3 |
| Переключить сортировку | S | — |
| Обновить библиотеку | R или F5 | — |
| Назад / закрыть окно / выйти из поиска | Esc | B / ○ |
| Меню | F10 | Start / Options |
| Справка | F1 | Back / View / Share |
| Кнопки в окнах | Стрелки (влево / вправо — между кнопками одного ряда) | Крестовина |
| Элементы формы | Tab / Shift+Tab | Крестовина / левый стик |
| Изменить аккаунт в выпадающем списке | Стрелки | Крестовина влево / вправо |
| Сохранить форму | Ctrl+Enter | Кнопка Сохранить → A / × |
| Прокрутить окно со справкой | PageUp / PageDown | Правый стик |
| При ожидании входа: открыть Steam / отменить | F8 / Esc | X / □ открыть, B / ○ отменить |
| Полный экран | F11 | Через меню |
| Выход | Ctrl+Q | Через меню |

Мышь: один клик выбирает карточку, двойной запускает. Поддержка геймпада использует стандартное браузерное сопоставление; физический контроллер здесь не проверялся. Ввод имени и пути требует клавиатуры или мыши.

## Данные и проверки

Свои игры, обложки, избранное и история сохраняются в `data/` рядом с приложением. Для другого места хранения задай `ORBIT_DATA_DIR`. Steam-файлы читаются, их содержимое не меняется. Поддерживается современный Steam appinfo v29; при другом формате названия берутся из установочных манифестов.

```bash
python3 -m unittest discover -s tests -v
node --check ui/app.js
python3 tests/switch_smoke.py
QT_QPA_PLATFORM=offscreen python3 tests/ui_smoke.py
```

Интерфейс — локальные HTML/CSS/JS в QtWebEngine; связь с Linux через QWebChannel. Отдельного веб-сервера нет.
