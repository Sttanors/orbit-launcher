## Orbit 0.2.4

- Исправлена ошибка CERTIFICATE_VERIFY_FAILED при проверке и скачивании обновлений на Linux, включая Arch / CachyOS: в сборку включён набор доверенных корневых сертификатов Mozilla.
- Сохраняется доверие к сертификатам системы и настройкам SSL_CERT_FILE / SSL_CERT_DIR. Проверка цепочки сертификатов и имени сервера остаётся обязательной для API GitHub, контрольных сумм и пакетов обновления.
- Добавлена команда `orbit --check-updates` для проверки обновлений через тот же HTTPS-код без открытия окна.

Пакеты: Windows x64 `.exe`, Debian / Ubuntu `.deb`, Fedora `.rpm`, Arch `.pkg.tar.zst`. Библиотека и настройки сохраняются.
