## Orbit 0.2.3

- На главном экране появились отдельные крупные кнопки **Скачать игру** и **Обновить Orbit**. Обновление открывается сразу с проверкой новой версии.
- В верхней панели доступна кнопка загрузок с количеством незавершённых загрузок.
- Завершённые торрент-загрузки автоматически добавляются в библиотеку. Orbit использует только файлы конкретной раздачи, исключает установщики, деинсталляторы и распространённые вспомогательные программы из автоматического выбора запуска; повторное добавление и дубли исключаются.
- Для готовой игры выбирается единственный подходящий файл запуска; на Linux Windows-игры настраиваются на установленный Proton. Если нужен выбор файла, установка, распаковка или Proton отсутствует, создаётся карточка **Настроить запуск**. Автодобавление можно отключить перед загрузкой.
- В завершённой загрузке отображается отметка о добавлении и кнопка перехода к игре в библиотеке. Скачанные программы автоматически не запускаются.
- Исправлено уведомление о завершении игры.
- Пользовательская автономная установка Linux обновляется в своём каталоге без замены системного пакета; переключение версий выполняется после проверки пакета.

Пакеты: Windows x64 `.exe`, Debian / Ubuntu `.deb`, Fedora `.rpm`, Arch `.pkg.tar.zst`. Библиотека и настройки сохраняются.
