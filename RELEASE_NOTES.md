## Orbit 0.3.1 — исправление обновлятора

- Исправлена установка в пользовательский каталог Linux: tar, zstd и скрипты перезапуска больше не наследуют несовместимые библиотеки встроенного Python / Qt. Новая версия запускается с очищенным окружением PyInstaller.
- Уже скачанный пакет проверяется по SHA-256 и используется повторно без повторной загрузки. После обрыва Orbit сохраняет часть файла и продолжает загрузку через HTTP Range, если сервер его поддерживает.
- Появились объём загрузки, процент и скорость. Обрывы повторяются до трёх попыток; если сеть недоступна, сохранённую часть можно докачать позже.
- Ошибки установки теперь видны в окне обновлений. Повтор установки использует проверенный пакет; диагностический журнал находится в папке данных `updates/updater.log`.
- Для Arch-пакета усилено сжатие zstd. Пакеты по-прежнему включают Python и QtWebEngine; небольшое изменение интерфейса требует скачивания полной сборки.

Windows x64 `.exe`, Linux `.deb`, `.rpm`, `.pkg.tar.zst`. Функция «Вечер на диване» из 0.3.0 включена. Библиотека и настройки сохраняются.

Исправления обновлятора начинают работать после установки 0.3.1. Для старых 0.2.4 / 0.3.0 с конфликтом системных библиотек может потребоваться однократный обход окружения или ручная установка.
